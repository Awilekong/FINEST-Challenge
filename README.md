# FINEST Robotic Insertion Challenge

Public website: https://awilekong.github.io/FINEST-Challenge/

This repository contains the static competition website in `site/`. GitHub Actions publishes only that directory to GitHub Pages.

The site includes the task description, five baselines, competition rules, tentative schedule, organizers and leaderboard. Resource and submission destinations display Coming soon until available.

Contact: Pengwei Zhang — zhangpengwei2024@ia.ac.cn

## Updating the website

Replace `site/` with the reviewed challenge build, then commit and push to `main`. The deployment workflow publishes the update automatically.

Research figures and videos are provided by the FINEST organizing team. Organizer portraits are supplied by the team or sourced from the organizers' academic homepages. No blanket license is assigned to third-party materials.
